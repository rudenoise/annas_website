# How to change the site and see your changes

No software needed — you do everything in your web browser on GitHub.

## 1. Open the page for editing
Go to this link (it opens the homepage text ready to edit):

**https://github.com/rudenoise/annas_website/edit/claude/nifty-gates-e8dbfb/index.html**

(If asked, sign in to GitHub first.)

## 2. Make your change
- Change the **words only**. Don't touch anything inside the angle brackets `< >`.
- For example, to set the fee, find `£XX` and type your price over it.

## 3. Save it
- Scroll up and click the green **Commit changes…** button (top right).
- A box pops up — click the green **Commit changes** button again.

That's it. You've saved. The site updates itself automatically.

## 4. See your change live
- Wait about **1 minute**.
- Open the site: **https://rudenoise.github.io/annas_website/**
- If you don't see the change, refresh the page. To be sure you're seeing the
  newest version, do a "hard refresh":
  - **Mac:** hold **Shift** and click the reload button
  - **Windows:** press **Ctrl + F5**
